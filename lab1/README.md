# Lab1 : Vector Processor Design Space Exploration

## Getting started

If you are working in the TI Lab computers or the VM, all dependencies are already set up for you.

You will need an access token to clone the repository. Generate an access token (under your account -> Preferences -> Access Tokens).

Run the following commands to get started:

```
cd ~
git clone https://gitlab.tuwien.ac.at/hls/aca_ws25/vicuna_edu.git
cd vicuna_edu
git submodule update --init --recursive
```
Now the repo is set up and you can work through the instructions in the Lab Manual.
